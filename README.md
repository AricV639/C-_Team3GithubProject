# C-_Team3GithubProject
Team project for Github Assignment.  
Aric V, Terrell P, Kyle, Anjelica M
Project
This project is a Windows Forms App that converts temperatures between Celsius and Fahrenheit. Each team member added a button with their name that displays a message in the listbox when clicked. The project was developed using GitHub with branches, commits, pull requests, and issue tracking.

How to run

Visual Studio: Open the solution and press F5.
.NET CLI: Run in project folder:

dotnet run
